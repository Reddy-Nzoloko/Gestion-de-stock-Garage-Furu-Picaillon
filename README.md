# Garage FURU / HAOJUE

Application PHP MVC de gestion de stock, compatible XAMPP, PHP 8.1+ et MySQL 8+.

## Installation

1. Démarrer Apache et MySQL dans XAMPP.
2. Importer `Script.sql` dans phpMyAdmin.
3. Vérifier les constantes de connexion dans `config/config.php`.
4. Ouvrir `http://localhost/GestionStockGarage/`.

L'application utilise PDO, des requêtes préparées et des transactions pour les achats et ventes. La palette visuelle est limitée au blanc cassé, au bleu foncé et au rouge pour les ruptures.
